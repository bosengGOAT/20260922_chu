# 🍽️ 식단관리 앱 (HTML 간단 버전)

순수 HTML/CSS/JavaScript로 만든 간단한 식단관리 앱입니다. **Node.js 없이 Go Live로 바로 사용 가능합니다!**

## 주요 기능

### 1. 프로필 관리 👤
- 개인 정보 입력: 이름, 나이, 성별, 키, 몸무게
- 활동 수준 설정: 거의 운동 안 함 ~ 매우 활발한 활동
- 식단 목표 설정: 체중 감량, 체중 유지, 체중 증가
- **자동 칼로리 목표 계산**: Harris-Benedict 공식 사용
- BMI 자동 계산

### 2. 식사 기록 🥘
- **세 끼 구분**: 아침, 점심, 저녁 각각 기록
- **두 가지 입력 방식**:
  - 직접 입력: 음식명과 칼로리 입력
  - 빠른 추가: 자주 사용하는 음식 18가지 버튼으로 빠르게 추가
- 기록된 음식 목록 확인
- 음식 항목별 삭제 가능

### 3. 칼로리 통계 📊
- **오늘의 총 칼로리**: 목표와 비교한 진행상황을 시각적으로 표시
- **식사별 칼로리 분석**: 아침, 점심, 저녁 각각의 칼로리 표시
- **목표와의 차이**: +/- 칼로리로 표시
- **실시간 업데이트**: 음식 추가/삭제 시 즉시 반영

### 4. 맞춤 추천 🎯
- **현재 상태 분석**: 칼로리 섭취 상황에 따른 동기 부여 메시지
- **BMI 기반 추천**: 저체중, 정상체중, 과체중, 비만 상태별 추천
- **3가지 추천 음식**: 현재 상태에 적절한 음식 추천
  - 칼로리 부족: 영양가 높은 음식 추천
  - 칼로리 초과: 저칼로리 음식 추천
  - 균형: 영양 밸런스 좋은 음식 추천

### 5. 날짜 선택 📅
- 과거/미래 날짜의 식단 관리 가능
- 날짜별로 독립적인 식단 기록 저장

## 설치 및 실행

### 필수 요구사항
- Node.js 16.0 이상
- npm 또는 yarn

### 설치 방법

```bash
# 1. 프로젝트 디렉토리로 이동
cd c:\Users\user\Desktop\20260116_cntjdgus

# 2. 의존성 설치
npm install

# 3. 개발 서버 시작
npm run dev

# 4. 브라우저에서 http://localhost:5173 접속
```

### 빌드

```bash
npm run build
```

빌드된 파일은 `dist` 폴더에 생성됩니다.

## 핵심 알고리즘

### 칼로리 목표 계산 (Harris-Benedict 공식)

**남성:**
BMR = 88.362 + (13.397 × 몸무게) + (4.799 × 키) - (5.677 × 나이)

**여성:**
BMR = 447.593 + (9.247 × 몸무게) + (3.098 × 키) - (4.33 × 나이)

**최종 칼로리 목표:**
- 활동 수준에 따른 배수 적용 (1.2 ~ 1.9)
- 식단 목표 적용 (감량: -15%, 증가: +15%)

### BMI 계산
BMI = 몸무게(kg) / (키(m))²

- BMI < 18.5: 저체중
- BMI 18.5 ~ 25: 정상체중
- BMI 25 ~ 30: 과체중
- BMI ≥ 30: 비만

## 주요 기능 상세 설명

### 자동 추천 시스템

**칼로리 상태별 추천:**
1. **칼로리 부족** (-300kcal 이상)
   - 계란, 아보카도, 견과류 등 고칼로리 음식 추천

2. **칼로리 초과** (+300kcal 이상)
   - 샐러드, 흰살 생선, 무염 팝콘 등 저칼로리 음식 추천

3. **균형** (-300kcal ~ +300kcal)
   - 현미, 닭가슴살, 브로콜리 등 영양 밸런스 음식 추천

### 빠른 음식 추가 버튼
미리 등록된 18가지 음식:
- 계란(1개) - 78kcal
- 밥(1공기) - 200kcal
- 돼지고기(100g) - 242kcal
- 닭가슴살(100g) - 165kcal
- 흰살 생선(100g) - 100kcal
- 우유(200ml) - 128kcal
- 바나나(1개) - 105kcal
- 사과(1개) - 95kcal
- 귤(1개) - 40kcal
- 브로콜리(100g) - 34kcal
- 당근(100g) - 41kcal
- 토마토(100g) - 18kcal
- 연어(100g) - 208kcal
- 소시지(1개) - 160kcal
- 치즈(30g) - 121kcal
- 요거트(100g) - 59kcal
- 아보카도(1/2개) - 160kcal
- 견과류 한줌(30g) - 200kcal

## 데이터 저장

모든 데이터는 **브라우저의 로컬스토리지**에 저장됩니다:
- `diet_app_profile`: 사용자 프로필
- `diet_app_meals`: 식사 기록

로컬스토리지는 브라우저를 닫아도 데이터가 유지됩니다.

## 사용 예시

### 1단계: 프로필 생성
```
이름: 홍길동
나이: 25
성별: 남성
키: 175cm
몸무게: 70kg
활동 수준: 중간 활동
식단 목표: 체중 유지
→ 자동 계산된 목표 칼로리: 약 2500kcal
```

### 2단계: 식사 기록
```
아침: 밥 200kcal + 계란 78kcal + 우유 128kcal = 406kcal
점심: 닭가슴살 165kcal + 현미 150kcal + 브로콜리 34kcal = 349kcal
저녁: 연어 208kcal + 밥 200kcal + 당근 41kcal = 449kcal
```

### 3단계: 통계 확인 및 추천 받기
```
총 섭취: 1204kcal
목표: 2500kcal
부족: 1296kcal
→ 영양가 높은 음식 추천 (계란, 아보카도, 견과류 등)
```

## 주의사항

- 로컬스토리지는 브라우저별로 독립적이므로, 다른 브라우저나 시크릿 모드에서는 데이터가 보이지 않습니다.
- 브라우저 캐시 삭제 시 데이터가 함께 삭제될 수 있습니다.
- 모바일 기기에서도 사용 가능합니다.
